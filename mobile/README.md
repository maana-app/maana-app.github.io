# معنا · تطبيق العميل (iOS / Android)

تطبيق حقيقي مبني بـ **Expo (React Native) SDK 58** و**Expo Router**، عربي من اليمين لليسار، وبخط IBM Plex Sans Arabic.

## الوضع الحالي
- يشتغل في **وضع المحاكاة**: لا رسائل حقيقية (رمز الدخول `4827`)، ولا دفع حقيقي، والبيانات محفوظة على الجهاز.
- لما تُضاف مفاتيح Supabase يتحول تلقائياً للوضع المباشر (`src/lib/api.ts`).
- الدفع الحقيقي **غير مربوط**. حسب قواعد المشروع، الربط ببوابة الدفع يحتاج موافقة صريحة من الرئيس التنفيذي.

## الشاشات
الدخول برقم الجوال → رمز التحقق → الرئيسية → صفحة الحملة → تأكيد الانضمام والدفع → تم الانضمام → طلباتي → تتبع الطلب → حسابي.

## التشغيل محلياً
```bash
npm install
npx expo start          # امسح الـ QR بتطبيق Expo Go على الجوال
npm run typecheck
npm run export:web      # نسخة ويب للمعاينة
```

## الوضع المباشر (Supabase)
1. أنشئ مشروع Supabase، وشغّل `supabase/migrations/0001_init.sql`.
2. فعّل الدخول برقم الجوال (Phone Auth) واربط مزود رسائل سعودي.
3. أنشئ ملف `.env`:
```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_ANON_KEY=...
```
السعر ورسوم التوصيل تُحسب في الخادم (`join_campaign`)، والتطبيق ما يرسل أي سعر.

| `npx eas-cli@latest build --platform ios --profile production` | التقنية |
| `npx eas-cli@latest submit --platform ios` ثم TestFlight للحملة التجريبية | التقنية |
| صفحة المتجر: الوصف، الصور، سياسة الخصوصية، رابط الدعم | التقنية + الرئيس التنفيذي |
| الإرسال للمراجعة | الرئيس التنفيذي |
