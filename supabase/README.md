# ma3na · waitlist database (Supabase)

Run `schema.sql` once in a new Supabase project (SQL Editor), then:
1. Put the new project URL and publishable key in `maanaco/index.html` (CONFIG.SB_URL / SB_KEY) and in `maanaco/admin/index.html` (SB_URL / SB_KEY).
2. Authentication → URL Configuration → Site URL = https://maanaco.com/admin/
3. The first person who signs in to /admin becomes Super Admin.
